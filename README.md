# Лабораторная работа: Массивы и алгоритмы сортировки на C#

##Тема
Разработка консольного приложения на C# с использованием математических функций и алгоритмов сортировки.

## Цель работы
Научиться работать с одномерными массивами, использовать методы для выполнения различных задач, включая сортировку массивов и сравнение времени выполнения различных алгоритмов сортировки.

## Функционал приложения
Приложение представляет собой консольный интерфейс, который позволяет пользователю:
1.  Генерировать одномерные массивы случайных чисел.
2.  Выполнять математические операции над элементами массива (поиск min/max, среднее значение, сумма и т.д.).
3.  Сортировать массив различными алгоритмами:
    *   Сортировка вставкой
    *   Сортировка Shell 
4.  Замерять время выполнения для каждого алгоритма и сравнивать эффективность.

Для запуска проекта необходимо иметь установленный **.NET SDK** (версия 6.0 или выше).
